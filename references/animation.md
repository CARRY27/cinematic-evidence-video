# 功能三：2D/3D 动画制作

动画的职责是让证据与因果更容易看懂，并形成可信的画面质感与节奏。此功能要求实际制作和复核可播放的运动画面；如用户只要求动画方案，才停在方案/分层设计。只做单镜头而缺镜头卡时，先从用户请求整理最小镜头 brief，不要求重做整片分镜。

## 输入与输出

输入为镜头卡、音轨及语音锚点、原始素材与许可边界、视觉规范、画幅/帧率/交付要求和现有工程。输出按用户要求包括可编辑源工程或分层素材、必要的贴图/素材来源记录、关键帧预览、连续短片，以及整片导出。保留原始资料副本，后期标注和重绘放在独立层。

## 选择 2D、3D 或混合

| 画面问题 | 优先方法 | 理由 |
|---|---|---|
| 阅读报道、文书、网页或数据图 | 2D 分层、标注与摄影机运动 | 保持原文可辨，重点随口播移动 |
| 解释数量、排队、资金流或抽象机制 | 2D 动画、可读的图表或简化空间 | 精确控制数值、比例、进出关系 |
| 需要展示实物结构、空间关系、遮挡、材质或具有意义的机位 | 3D 物件、灯光与摄影机 | 空间变化本身帮助解释 |
| 先呈现真实来源、再解释其机制 | 原始影像/截图 + 2D/3D 合成 | 清楚区分“发生过的画面”和“帮助理解的画面” |

3D 的建模、打光和渲染成本只有在表达收益明显时才值得承担。不能用简单平面元素挤出厚度来冒充写实物体；也不要把新闻原图无标注地贴到 3D 场景当作现场画面。

## 制作方法

1. **统一美术方向。** 从题材、真实素材和参考片确定字体、色彩角色、材质、光比、颗粒、景深与镜头速度。先做代表镜头的静帧和运动样段，检查在目标屏幕大小下是否仍清晰。
2. **2D：分层而非平移整张图。** 原图保持可追；标注、标题、数字、遮罩、投影与背景各自可控。数据图先算对数值、同量尺和观察期，再安排显示顺序。低像素来源近原生展示，需要大字时另做明确标注的摘录。
3. **3D：先定物体和镜头，再加效果。** 确定物体比例、轮廓与材质参考；设置能解释形状的主光、环境光、接触阴影与可信反射；通过推、绕、跟或物体动作改变信息焦点。景深与运动模糊不能遮住事实文字或主体细节。
4. **动画与配音同步。** 每镜给运动起因、速度变化、落点与呼吸时间。关键数值应在对应口播时可读；音效只强化物理动作或叙事转折，人声始终可懂。
5. **小样先行。** 先渲真实资料接动画、复杂数据、低清文书和 3D 核心物体等高风险镜头。检查首/中/尾帧及连续运动，修完才做全段与整片；不要凭软件预览或代码参数宣称已解决画面问题。
6. **合成与导出。** 保持画幅、帧率、色彩和音轨一致；检查字幕安全区、界面可读性、黑帧、闪烁、穿模、边缘抠像及音画切点。导出用户所需版本，逐个核参数并全片播放/解码。

工具由宿主环境决定，可用 NLE、合成软件、2D/3D 软件或代码渲染。可调用脚本验片；如果宿主无法运行脚本，使用其现有媒体检测方式。先尝试当前环境中可用的渲染途径；确实无法渲染时交付可转移的源工程/镜头方案，并明确标注预览、整片和技术验收尚未完成。

## 质量判断

技术正确仅是底线。对照参考片的实际片段检查物体质感、层次和光、构图张力、连续运动、真实材料密度、叙事节奏与声音力量。记录差距的时间码、画面证据与改后结果；用户要求“达到样片效果”时不能靠分辨率或主观宣称替代逐镜复看。
