# 功能二：专业分镜

目标是让另一位制作人仅凭镜头表和素材清单即可制作，也让审片人能按时间码指出不足。已有精确分镜时针对性修订，不用新模板覆盖用户的镜头结构。

若只要求制作一个镜头而没有镜头卡，先根据请求写最小镜头 brief：表达目标、口播/时长、主体、画面身份、起止状态、交付画幅和素材风险；不强迫补齐整片分镜。

## 输入

使用通过本次内容核查的口播稿或锁定原稿、最终或临时配音、事实/素材来源表、目标平台与画幅、安全区要求、参考片和现有成片。若还没有配音，镜头时码标记“待音频锁定”，不要声称精确到帧。

## 分析与设计

1. **拆参考片。** 逐段观看非真人画面，记主视觉、真实资料介入点、构图层次、镜头运动、变化发生的时刻、声效和切点。比较的是镜头承担的叙事职责和画面张力；不同画幅允许重新构图。
2. **给每镜一个明确职责。** 常见职责包括建立实物、提出问题、举出原始证据、引导读证据、解释机制、对比数字、展示后果和情绪收束。一镜可复合，但观众注意力应有主次。
3. **设计证据接力。** 对关键主张，尽可能安排可辨的原图/报道/实拍 → 镜头或标注指向相关位置 → 清楚标明身份的重绘/概念动画。每次转换写明画面身份；不要把不同年份页面剪成同一时刻。
4. **设计运动弧。** 写出起始状态、运动原因、焦点转移、结果和停留。相邻镜头检查主体、景别、色彩密度与动作方式是否连续重复；有意回扣同一视觉时，说明状态如何改变。
5. **画面与声音对时。** 为关键数字、转折词和情绪峰值记录语音锚点；数据到达、推近落点、切镜与声音要对应。有正式配音就以实际波形/听感计时。
6. **可制作性预演。** 对最高风险镜头做 styleframe、关键帧或短 animatic，确认素材像素、字幕区域、复杂运动和可能的渲染成本。2D/3D 选择必须说明表达收益与制作代价。

## 每张镜头卡的最小字段

镜头 ID；入/出时间或待锁时码；对应口播句与语音锚点；本镜主张/情绪目的；原始证据及来源；画面身份（原图、摘录、重绘、概念）；主体、构图、景别、文字层级；运动起点/关键状态/结束与停留；2D/3D/实拍的选择；转场与声音；画幅安全区；真实性、权利或技术风险。

输出全片镜头表、素材/主张对应表、节奏与主体变化概览，以及最难镜头的预演或可执行说明。若用户只要分镜，不把尚未渲出的动画宣称为成片。

## 验收

按口播顺序逐镜读表，确认没有无画面的抽象长段、重复底板、错位数字、证据出处缺失、误导性比例尺或越过字幕安全区的重点。按实际可用素材复查每镜是否能完成；缺少证据时修改镜头主张或列出待补材料，不伪造新闻画面。待决事实对应镜头可以做视觉试验，但不能以已证实内容进入最终成片。
